# Dhruvil Valand - Portfolio

Open `index.html` in your browser (double-click) - no install needed.

## Folder structure
- index.html  : all content (text, projects, contact details)
- css/style.css : design. Colours and font are at the top (":root")
- js/script.js  : behaviour. Email + typing words are at the top ("SETTINGS")
- assets/images : your photos
- assets/resume : your resume PDF

## Easy updates
- Text: edit index.html (sections are labelled with comments).
- New project: copy one `<article class="project">` block, change text/links.
- Live demo links: replace `href="#"` in each project.
- Colours: change `--primary` and `--accent` in css/style.css.
- New photo: replace assets/images/dhruvil.jpg (keep the name).
- New resume: replace assets/resume/Dhruvil_Valand_Resume.pdf (keep the name).

## Publish for free
Upload the folder to GitHub Pages, Netlify or Vercel.
